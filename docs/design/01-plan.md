## 4. S4 激活门禁（D-013 + D-016 修订）

激活须**同时满足**：①30 日滚动资金费率年化 **>20%**；②OTC/离岸合规风险清单通过；③**首轮额度 ≤ 总额 10%**；④新 D# 记录激活。8% 回撤线不覆盖 S4 尾部风险——由权重上限防。当前 5–11% → 只监控。

## 14. 收益阶梯与动态资本路由（D-024/D-025）

| 档位 | 结构 | 名义收益 | 风险 | 不赌 |

**路由规则（监控引擎驱动）**：资金驻留基档 → funding 30 日 >15% 路由进套利 → 月末/季末路由进逆回购时点 → Launchpool 日历路由进稳定币池 → 平时归位基档。持有层（TRX/BNB 等）单列，不计套利口径。

**计价币种陷阱规则（D-024）**：以非稳定币计价的收益 ≠ 真实收益（Babylon 教训：BABY −92%）。

**D-026 定稿（2026-08-15 决策层裁定）**：保本凸性 50%（10 万：民营定期 5 万 + 灵活保本 4.5 万，利息 ~2,150 → 1,000 季滚期权 + 1,150 留存）+ 稳定币基档 50%（10 万：2–3 所定期档 4.5–6%，分 3 批）+ 动态路由增强。地板 +2.15% / 基准 ~3.2–3.7% / 贬值 ~5.2% / 牛市 8–10%+。均衡卫星推迟（3 个月无事故后 D# 评估）。执行顺序：①出入金 1 万验证 → ②国内半仓（T+0）→ ③稳定币分 3 批 → ④期权季滚 → ⑤监控 v1 上线 → ⑥TRX 优化独立执行。
