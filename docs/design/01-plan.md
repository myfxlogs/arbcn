## 4. S4 激活门禁（D-013 + D-016 修订）

激活须**同时满足**：①30 日滚动资金费率年化 **>20%**（含 3–4% 往返摩擦摊销）；②OTC/离岸合规风险清单通过；③**首轮额度 ≤ 总额 10%**（两个季度运营干净后经新 D# 评估提额）；④新 D# 记录激活。8% 回撤线不覆盖 S4 尾部风险——由权重上限防。当前 5–11% → 只监控。

## 7. 风控

- 回撤硬线 8%：适用 S0–S3，触线减风险层（先 S3 再 S2）。
- 权重硬帽：S4 ≤10%（首轮）、S3 ≤25%、S2 ≤20%。
- 汇率敞口：USD 按批次记成本价；USD/CNH < 6.6 停止加仓。
- 灰色层人工留痕：每笔记录通道/对手方/额度/时点。

## 11. 审计结论（2026-08-15 自审计）

2026 年国内零售市场"真套利"通道结构性枯竭：打新需 500 万+冻结资金、LOF 套利被退市新规终结、转债打新萎缩。20 万本金真实可得的无风险套利 = 逆回购时点 + 存款/国债利差。最优解 = 无风险层效率最大化（S1 2.3%）+ 15% 美元分散 + 双低转债容量匹配 + 条件引擎（S4/改革触发器）。审计中两项提案被数据证伪（北交所打新、QDII-LOF），已弃——见 D-015、practices.md 打回模式 #1。
